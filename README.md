# Heimdall releases

Installers for [Heimdall](https://github.com/TheDarkCitadel/Heimdall), instant private voice dictation for Windows.

Download the latest `HeimdallSetup-x.y.z.exe` from [Releases](https://github.com/TheDarkCitadel/Heimdall-releases/releases/latest). Installed copies of Heimdall update themselves from here.
